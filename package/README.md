# 境月箱（kyogetsukan kyogetsubako）

境月館のツールを、これ一つに。

境月箱は、境月館の各ツール（モジュール）を載せて呼び出すための無料の土台です。
対応モジュール（ユニパケ）を取り込むと、`Tools > 境月館 > 境月箱` のウィンドウに自動で並びます。

## 使い方

1. VCC / ALCOM でこの土台（境月箱）を追加する
2. 境月館の対応モジュールのユニパケをプロジェクトにインポートする
3. メニュー `Tools > 境月館 > 境月箱` を開くと、入れたモジュールが一覧に出ます

## 仕組み

- 土台（境月箱）は無料。更新は VCC から自動で届きます。
- 各モジュールの機能本体は、モジュールのユニパケ側にあります。土台だけでは動きません。
- 新しいモジュールが増えても、土台を入れ直す必要はありません。差し込み口に沿ったユニパケを入れるだけで並びます。
